# OFFBALL

Proyecto académico de scouting de fútbol basado en análisis de datos y modelos de inteligencia artificial.

## Objetivo
Explorar datos de fútbol para obtener perfiles estadísticos de jugadores y estimar su valor de mercado como apoyo al análisis de scouting.

## Estado del proyecto
Este repositorio se irá completando durante el desarrollo. Las secciones marcadas como pendientes todavía necesitan código, evidencias o validación.

## Estructura
- `big_data/`: ingesta y procesamiento con Hadoop y HDFS.
- `data/`: diccionario y documentación de los datos. Los datasets completos no se incluyen por defecto.
- `limpieza/`: ensuciado controlado y limpieza.
- `notebooks/`: análisis exploratorio y experimentos de IA.
- `models/`: código y artefactos de los modelos.
- `api/`: API de consulta de modelos con FastAPI.
- `mlflow/`: configuración e instrucciones de seguimiento y despliegue.
- `docs/`: documentación técnica del proyecto.

## Tecnologías
Python, Hadoop, HDFS, Jupyter Notebook, pandas, scikit-learn, MLflow y FastAPI. La integración y el estado real de cada tecnología se documentarán conforme se verifiquen.

## Datos
Los datos utilizados proceden de Transfermarkt. Consulta `data/README.md` para conocer qué ficheros deben documentarse y cómo se gestionan.

## Instalación
Las instrucciones definitivas se añadirán cuando se cierre el entorno de ejecución y sus dependencias.

## Ejecución
Consulta los README de cada apartado. No todos los componentes están terminados todavía.

## Limitaciones
Los resultados de los modelos son estimaciones estadísticas y no sustituyen una valoración profesional ni garantizan el rendimiento futuro de un jugador.
